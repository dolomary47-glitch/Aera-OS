# Aera OS — References Directory

Ce dossier contient des thèmes et composants externes utilisés comme **références techniques et visuelles** pour le développement d'Aera OS.

## Contenu

- `Rounded-Rectangle-dark-transparent/` : Thème de référence GNOME Shell issu de la communauté.
  - Sert d'exemple pour la structure des sélecteurs GNOME Shell, l'organisation des assets SVG et les techniques de transparence.
  - **IMPORTANT :** Ce dossier est une archive de référence en lecture seule. Il ne doit **PAS être modifié**.
  - Les valeurs graphiques (couleurs, rayons, opacités) d'Aera OS proviennent exclusivement de `design-system/tokens.json`.
